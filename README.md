# ⏰ 초등학교 교실용 쉬는 시간 알람 & 안내판 웹 앱

초등학교 교실의 대형 TV, 전자칠판(스마트보드), 빔프로젝터에 띄워두고 사용하는 **귀엽고 시인성이 뛰어난 쉬는 시간 알람 및 학급 안내판**입니다.

별도의 복잡한 설치 과정 없이 `index.html` 파일을 더블 클릭하여 브라우저에서 바로 사용할 수 있습니다.

---

## 🌟 주요 기능 안내

### 1. ⏰ 대형 실시간 시계 & 쉬는 시간 타이머
- **실시간 시계**: 오늘 날짜(요일)와 오전/오후 현재 시간을 초 단위까지 큼직하게 표시합니다.
- **원형 게이지 타이머**:
  - 기본 10분으로 설정되어 있으며, 상단의 `5분`, `10분`, `15분`, `20분` 버튼으로 1초 만에 시간 변경 가능.
  - 쉬는 시간 중 `+1분`, `+3분`, `+5분`, `-1분` 버튼으로 즉시 시간 연장 및 단축 가능.
  - **1분 전 알림**: 쉬는 시간 종료 1분 전에 '또롱-' 하는 예고 차임벨이 울립니다.
  - **종료 축하 & 알람**: 시간이 다 되면 **실로폰 학교 종소리(딩동댕동)** 와 함께 **축하 색종이(Confetti) 폭죽**이 화면 가득 터집니다.

### 2. 📢 오늘의 교실 알림판 (공지사항)
- 다음 시간 준비물, 알림장, 쉬는 시간 안전 수칙을 예쁜 카드 메모지 형태로 표시합니다.
- 미술, 체육, 급식, 음악, 청소 시간 등 **원클릭 프리셋 버튼**으로 자주 쓰는 안내 문구를 즉시 불러올 수 있습니다.

### 3. ✨ 교실 미디어 & 힐링 갤러리 (탭 전환)
- **🐥 마스코트 뷰**: 쉬는 시간 동안 응원 한마디를 건네는 귀여운 캐릭터(클릭 시 대사가 바뀝니다).
- **🖼️ 사진 뷰**: 우리 반 친구들의 단체 사진이나 미술 작품 사진을 파일 업로드 또는 링크로 띄워둘 수 있습니다.
- **🎬 영상 뷰**: 쉬는 시간 스트레칭 체조 영상, 명상 음악, 교육 유튜브 영상 링크를 넣어 바로 재생할 수 있습니다.

### 4. 🎨 귀여운 테마 4종 지원
- 🐥 **퐁퐁 노랑병아리반** (기본 테마 - 따뜻한 노랑/주황)
- 🌿 **싱그런 새싹반** (초록/라임)
- 🌸 **달콤 솜사탕반** (파스텔 핑크/보라)
- 🚀 **반짝 별빛우주반** (신비로운 우주 다크 테마)

### 5. 🎲 특별 교실 보너스 도구
- **발표자 / 당번 뽑기 (`🎲 발표자 뽑기` 버튼)**: 우리 반 번호 범위 내에서 무작위로 행운의 번호를 뽑아주는 재미있는 룰렛 도구 (축하 팡파레 효과음 포함).
- **빗소리 ASMR (`🌧️ 빗소리 ASMR` 버튼)**: 차분한 쉬는 시간 분위기를 만들어주는 Web Audio 백색소음 기능.
- **전체화면 모드 (`⛶ 전체화면` 버튼)**: 교실 화면에 꽉 찬 깔끔한 모드로 즉시 전환 (`F11` 또는 버튼 클릭).

---

## 💻 사용 방법

1. `index.html` 파일을 웹 브라우저(Chrome, Edge, Whale 등)로 엽니다.
2. 우측 상단의 **[⚙️ 교실 설정]** 버튼을 눌러 우리 반 이름(예: `3학년 1반`), 기본 쉬는시간, 공지사항을 입력합니다.
3. 설정한 내용은 브라우저에 자동 저장되므로, 다음번에 켜도 그대로 유지됩니다!
4. 쉬는 시간이 시작되면 **[▶ 시작하기]** 버튼을 누르세요.

---

## 🎵 사운드 안내
- 모든 효과음과 알람음은 **Web Audio API**를 통해 실시간으로 합성되므로, 별도의 MP3 음원 파일 다운로드 없이 인터넷이 끊긴 오프라인 환경에서도 100% 정상 작동합니다.
